## Validation and trust

These are locally reviewed built-in wrapper instructions. Their provenance, allowed
department scopes, fingerprints, local data and absence of automatic hooks are tested.
This does not claim an independent model reviewed each archive, that third-party code
was executed/tested, or that an external service is installed. Raw source material
never gains native authority solely from appearing on disk. New runtime candidates
still use the existing guarded registration, tests, independent QA and activation flow.

Source guidance is subordinate to the user/root contract and the wrapper. Absolute
global dotfiles, auto-resume/session hooks, automatic installs, paid models, messages,
publishing, deployment, hidden reasoning and active instruction edits are disabled.
gstack deployment/cookie/upgrade scripts, Superpowers blanket agent dispatch/hooks,
Claude session rewrites and task-observer automatic authority do not replace the
existing Management/Vault/QA/update process. Reuse their relevant review/design/
verification methods, scoped to the assigned task. References to unbundled binaries
or support tools are explicitly uninstalled/unverified, not working commands.

## Useful capabilities retained

- UI/UX: seven scoped visual/design references and actual read-only CSV search data;
  currentness is ARCHIVED_GUIDANCE_UNVERIFIED_CURRENTNESS. No default framework.
- Taste: frontend/app-screen direction and reference rules; subjective preferences
  stay distinct from universal accessibility evidence. No browser installer/scripts run.
- Knowledge Work: relevant design, engineering, marketing, analytics and source-research
  methods. Unrelated HR/legal/finance/biomedical plugins are preserved references.
- gstack, Superpowers, Claude skills: selected review, debugging, planning, verification
  and handoff methods. Native source hooks/services are inactive; review is still separate.
- YouTube, Instagram and video packs: planning, copy/scripts, captions, creative briefs
  and internal checks; actual trends/limits/private analytics require current evidence.
  Publication, comments/DMs, scraping and paid media tools need actual scoped access.
- Task Observer: actual friction/lessons feed the existing Research/Health/update pipeline;
  no silent self-modifying instruction layer. CC BY author/license notices retained.
- Free API list: research candidates only. No free-tier, quota, privacy, availability
  or price claim becomes verified, and no provider/account is automatically selected.
- Hyperframes: pinned production/format/media guidance. HTML/storyboards are not MP4s.
- Headroom: pinned compatibility/cost evaluation only. No claimed token savings,
  interception of approval/security text or replacement of the SQLite system of record.

## Upstream substitutions and licensing

The two ZIPs exceeded the transfer tool's 32 MiB limit. User-provided repository URLs
were read and fetched as pinned subsets. Their commits/file receipts are in
V05-HYPERFRAMES-SOURCE.json and V05-HEADROOM-SOURCE.json. They are not asserted
byte-identical to the untransferred ZIPs. No source installer/build script was run.

Original supplied license/notices are retained per package; missing license metadata
(including the free-API list and standalone script archive) remains UNKNOWN and grants
no inferred third-party rights. Wrapper adaptations are identified as root integration
changes. Verify rights before downstream redistribution/use of assets or private data.
Archive symlink entries were skipped rather than executed; this is not a claim they
were malicious. No original vendor source was modified.
