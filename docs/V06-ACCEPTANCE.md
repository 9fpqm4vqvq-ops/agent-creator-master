## Security and remaining deployment work

Production has no mock fallback. Invocations have separate receipts/cost holds.
Unknown outcomes retain reservations and require diagnosis; ambiguous external
operations are never automatically replayed. Secrets and operational databases,
workspaces and outputs are excluded from releases.

Generated commands need reviewed argv authorization and actual OS isolation.
Containers lack network, host repository/socket and model keys. File guards do not
replace isolation. Dependencies/browser checks require compatible reviewed images.
Operators and QA must choose meaningful functional checks: a trivial passing
command does not prove acceptance. Codex still needs host filesystem restrictions;
its adapter rejects enabled MCP servers. Claude tools/MCP are disabled.

General search, rendering, Figma/Drive, publishing, analytics, Notion and deployments
need supported adapters, credentials, permissions and actual verified calls. No
unconfigured service is labelled operational. No content, deployment, purchase,
message or trade was executed in validation.

This is an executable integration release with remaining live acceptance
requirements, **not certification for unattended production or autonomous business**.
